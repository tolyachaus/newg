# Дитячий центр розвитку «NewG» (м. Луцьк) - Вебсайт

Сучасний, адаптивний вебсайт для Дитячого центру розвитку **«NewG»** (м. Луцьк), створений для публікації на **GitHub Pages**.

---

## 🌟 Особливості сайту
- **Повна відповідність структурі оригінального сайту (`newg.com.ua`)**:
  - Герой-банер з контактами, посиланням на Instagram та каруселлю фотографій.
  - Місія центру («Добре там, де тебе люблять!»).
  - Усі 6 напрямків послуг:
    1. Садок повного та неповного дня (3-5 років)
    2. Підготовка до школи “STREAMS” & Класична (5-6 років)
    3. Театральна майстерня (5-14 років)
    4. Індивідуальна англійська мова (3-14 років)
    5. Заняття з логопедом (від 3 років)
    6. Літній табір «WONDERcamp» (6-10 років)
  - Інтерактивна фотогалерея вихованців.
  - Сторінки Акцій та Блогу (`/promo/`, `/blog/`).
  - Модальні вікна «Безкоштовне пробне заняття» та «Зателефонуйте мені!» з інтерактивними формами та повідомленнями для користувача.
- **Дизайн та анімація**:
  - Фірмова колірна гама (Червоний `#ff000b`, Блакитний `#00b5e8`, Темний `#13171c`).
  - Шрифти **Bebas Neue** (заголовки) та **Montserrat** (основний текст).
  - Скляний фіксований хедер (Glassmorphism effect).
  - Мобільне висувне меню (Drawer menu).

## 🚀 Як завантажити сайт на GitHub та увімкнути GitHub Pages

### Крок 1. Ініціалізація Git репозиторію
Відкрийте термінал у цій папці та виконайте команди:

```bash
git init
git add .
git commit -m "Initial commit for NewG website"
```

### Крок 2. Створення репозиторію на GitHub
1. Перейдіть на [GitHub.com](https://github.com) та натисніть **New repository**.
2. Вкажіть назву репозиторію (наприклад, `newg-website` або `newg`).
3. Оберіть **Public** (Публічний).
4. Натисніть **Create repository**.

### Крок 3. Прив'язка та відправка коду в GitHub

```bash
git branch -M main
git remote add origin https://github.com/ВАШ_НІКНЕЙМ/newg-website.git
git push -u origin main
```

### Крок 4. Увімкнення GitHub Pages
1. У вашому репозиторії на GitHub перейдіть у **Settings** (Налаштування) → **Pages**.
2. У розділі **Build and deployment** під заголовком **Source** оберіть **Deploy from a branch**.
3. У випадаючому списку гілок оберіть **main** / **`/ (root)`** та натисніть **Save**.
4. Через 1-2 хвилини ваш сайт буде доступний за адресою:
   `https://ВАШ_НІКНЕЙМ.github.io/newg-website/`
